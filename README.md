# সহজে ইনকাম (Sohoje Income) — ভেরিফাইড ডিজিটাল মাইক্রো-টাস্ক ও রিওয়ার্ড প্ল্যাটফর্ম

## পিসি বা সার্ভারে রান করার নিয়ম:
1. প্রথমে Node.js ইন্সটল থাকতে হবে।
2. ফোল্ডারটি আনজিপ (Unzip) করে টার্মিনালে ওপেন করুন।
3. ডিপেন্ডেন্সি ইন্সটল করুন:
   npm install
4. লোকাল সার্ভার চালু করুন:
   npm run dev
5. প্রোডাকশন বিল্ড তৈরি করতে:
   npm run build

## ফ্রিতে Vercel বা Netlify-তে পাবলিক করার নিয়ম:
1. এই ফোল্ডারের সব ফাইল GitHub-এ একটি নতুন Repository খুলে আপলোড করুন।
2. https://vercel.com বা https://netlify.com এ গিয়ে আপনার GitHub Repository টি Import করে Deploy বাটনে ক্লিক করুন।
